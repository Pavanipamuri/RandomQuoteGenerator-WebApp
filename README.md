# Random Quote Generator Web App

A simple Random Quote Generator Web App built using HTML, CSS and Python Flask.

## Features

* Displays random motivational quotes
* Show More button for generating new quotes
* Different quote displayed on every click
* Clean and responsive user interface
* No repeated quotes consecutively

## Technologies Used

* HTML
* CSS
* Python Flask

## Project Structure

RandomQuoteGenerator-WebApp/
├── app.py
├── templates/
│   └── index.html
├── static/
│   └── style.css

## How to Run the Project

1. Install Flask
   pip install flask

2. Run the application
   python app.py

3. Open browser and visit
   http://127.0.0.1:5000
